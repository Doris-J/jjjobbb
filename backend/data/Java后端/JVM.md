# JVM

### Q1：JVM 内存区域有哪些？各自的作用是什么？

线程私有：
- 程序计数器：当前线程执行的字节码行号指示器
- 虚拟机栈：Java 方法执行的栈帧（局部变量表、操作数栈等）
- 本地方法栈：Native 方法执行

线程共享：
- 堆：对象实例分配区域，GC 主要区域
- 方法区（元空间）：类信息、常量、静态变量、JIT 编译代码
- 运行时常量池：方法区的一部分，存放字面量和符号引用

---
### Q2：什么是 GC Roots？可以作为 GC Roots 的有哪些？

GC Roots 是垃圾回收的起始点，从这些对象出发，不可达的对象会被标记为垃圾。

可作为 GC Roots 的对象：
1. 虚拟机栈（栈帧的局部变量）中引用的对象
2. 方法区中类静态属性引用的对象
3. 方法区中常量引用的对象
4. 本地方法栈中 JNI 引用的对象
5. JVM 内部引用（基本类型Class对象、常驻异常对象等）
