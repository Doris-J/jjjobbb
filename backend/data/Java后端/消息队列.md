# 消息队列

### Q1：消息队列的作用有哪些？ [easy]

1. 解耦：生产者和消费者不直接依赖，降低系统耦合度
2. 异步：耗时操作异步处理，提高响应速度（如发短信、发邮件）
3. 削峰填谷：高峰期消息堆积在队列，消费者按能力消费，保护下游服务
4. 顺序消费：保证消息按顺序处理（Kafka 分区内有序）
5. 广播：一条消息被多个消费者消费

---
### Q2：如何保证消息不丢失？ [hard]

从三个环节保证：

生产者：确认机制（Kafka acks=all；RocketMQ 同步发送+重试）

Broker：持久化（Kafka 写磁盘；RocketMQ 同步刷盘）；多副本（Kafka 副本机制；RocketMQ 主从同步）

消费者：手动提交 offset / ACK（处理完再提交，避免自动提交导致未处理就提交）；消费失败进入重试队列 / 死信队列
